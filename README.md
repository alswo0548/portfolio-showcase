## 수정

- `index.html`: 랜딩 페이지
- `octv.html`, `gdq.html`, `climbing.html`: 프로젝트별 시연·기여·증거
- `styles.css`: 반응형 디자인
- `media.js`: 자동재생·지연 로딩·실패 시 애니메이션 대체
- `assets/`: 기존 실제 녹화·캡처

빌드가 필요 없는 정적 사이트입니다. 자동 커밋 워크플로와 공동작성자 서명을 추가하지 않습니다.
